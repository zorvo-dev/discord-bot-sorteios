# Bot de sorteios para Discord

Bot feito em Python (discord.py) que cria sorteios com um comando.

## Funcionalidades
- /sorteio com prémio, duração e número de vencedores
- Botão "Participar" (sem participações duplicadas)
- Anuncia os vencedores automaticamente

## Como usar
1. Instala as dependências: pip install discord.py python-dotenv
2. Cria um ficheiro .env com DISCORD_TOKEN e GUILD_ID
3. Corre: python bot.py
